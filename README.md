# K3s 使用手册

> 单机 K3s 从安装到实战的完整记录，以 **Docker Compose 迁移**为主线。

---

## 这套文档适合谁

从 Docker / Docker Compose 过来、想把手里的服务迁到 K3s 的人。

所有例子都来自真实在跑的服务，不是玩具 demo。环境是**单机 K3s**，无外部依赖，不需要云厂商。

## 阅读路径

**第一次接触 K3s**，按顺序读：

```text
00 装好机器 → 01 学会看 → 02 部署第一个服务
           → 03 给它域名和 HTTPS → 04 让它存住数据
```

**已经有集群、只想查东西**，直接跳：

- 命令忘了 → [01 基础命令](k3s-01-基础命令.md)
- 域名或证书不通 → [03 路由配置](k3s-03-路由配置.md)
- 数据存不住 / Pod 起不来 → [04 存储挂载](k3s-04-存储挂载.md)

## 几个贯穿全篇的约定

- 文档目录统一放在 **`/opt/k3s/`**
- 一个服务一个子目录，改哪个服务只动它自己的文件
- 示例围绕 **frps**、**vaultwarden**、**pairdrop**、**nginx**、**openlist** 这几个真实服务
- 每份文档的第一章都是「动手」，概念和进阶内容放后面
